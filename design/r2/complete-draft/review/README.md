# Open the design review

Download `index.html` and open it in Chrome or Edge. It shows the actual saved isometric, front, rear and interior CAD views immediately; use **Enable rotatable 3D** only when you want to rotate the embedded draft mesh.

`saved-views.html` is the smaller image-only version. Its four view buttons work without JavaScript or WebGL. `overview.png` is the same saved isometric CAD image for direct viewing.

These files are generated by `../make_review.py` from the checked draft STL and saved CAD PNGs. They review the existing geometry; no final print release or physical-fit approval is implied. The reported phone/wheel/motor dimensions and remaining fit inputs are in the parent README.
