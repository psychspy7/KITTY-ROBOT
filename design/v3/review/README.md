# Open KITTY V3 Signature

Download `index.html` and open it in Chrome or Edge. It shows actual saved V3 CAD views immediately. Choose Front, Rear angle, Side, Inside or Tail joint; click **Enable rotatable 3D** for the matching embedded draft mesh. `saved-views.html` is the smaller backup and needs no JavaScript or graphics driver.

V3 has a shorter neck and lower face, clipped bezel corners, a protected rounded sensor opening, rounded vents, a folded chest collar, matching faceted neck cuff, two rear cable-tie eyes and a tail-removal arrow and a smaller detachable-tail mount. The page includes a measured comparison with R2.1. Eye graphics and bought hardware are reference envelopes for appearance/layout review.

`overview.png`, `side.png`, `tail-joint.png` and `neck-cable-eyes.png` are direct native CAD views. The exploded tail view omits the proposed cross screw and pulls the tail 35 mm rearward. Final STL release follows the user's shape decision and remaining fit/printer checks in the parent README.
